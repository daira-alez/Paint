#Original de paint
Este es un juego que permite dibujar diferentes formas geómetrica mediante la selección de la tecla en minusculas de la inicial de la forma:
c: cuadrado
Y el cambio de color:
R: rojo
B: azul
k: negro
G: verde
Para este juego se realizaron las modificaciones para añadir la funciones para círculo, rectángulo y triángulo.
r: rectángulo
c: círculo
t: triángulo
Además se añadio el color amarillo:
Y: amarillo
Estos cambios permiten que el juego sea más completo.
